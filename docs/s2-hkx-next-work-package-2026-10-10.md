# HKX 下一工作包：一个真实活跃 clip 的取数与独立采样

日期：2026-10-10。依据：[PRD 0.7 §6.4](player-panel-prd.md)。本文件是下一轮准备与回传协议；现有 HKX12 DLL 不因文档更新获得新能力。

## 本轮只关闭一个问题

能否在正常播放生命周期中，取得并安全持有一段明确动画，再用自己的时间做只读采样？
摆骨骼、画面随动、骨名桥接已有证据，不重复做正弦观感试验。注册表空值／包装指针失败只说明对应取数解释失败，不直接否定引擎采样。

## 发包前的静态准备

1. 固定游戏／SKSE／CommonLib、参考 OAR commit 和源码提交；仅参考 OAR 源码，不调用其运行时接口。
2. 根据真实 Activate／Load／Update／采样调用核对签名、类型、字段和生命周期阶段，记录证据定位。
3. 明确观察的是正在执行的实例；名字与索引仅做交叉核对。无需为了观察而额外激活或推进源角色。
4. 明确资源／加载器的持有与卸载关系，包括压缩数据、binding、轨道表；不能用裸指针加 VirtualQuery 校验替代所有权。
5. 配置本轮只观察一个已知 Idle，设有界日志与停止条件。不批量扫陌生层，不把 CRC 命中直接当可调用动画。
6. 不能说明以上关系时，不发新的上机包，回报缺的结构／ABI／持有证据。

参考线索：[OAR ActiveClip.cpp](https://github.com/ersh1/OpenAnimationReplacer/blob/main/src/ActiveClip.cpp) 的真实播放／混合路径使用 animationControl→binding→animation 采样。
这说明接口不应被普遍判死，但不证明本项目当前扫描的对象等同于它；实施时固定版本并核对目标运行时。

## 最小运行实验

1. 从最终 zip 安装匹配 DLL／PDB，记录哈希与 manifest；不混用上一轮或中间构建。
2. O 在正常游戏中自然播放所选 Idle 时，被动观察一次真实 clip 生命周期。记录 actor、graph／context、clip 身份、活动依据、实际动画／替换文件、对象与资源来源。
3. 确认动画与绑定有效且已被安全持有后，再进入暂停背包；确认不是临时 borrowed 对象、不会因暂停或源图更换立即失效。
4. 在相同 t 重复采样，然后在至少三个已声明的不同相位采样，检查数量、有限值、轨道映射和内容变化。不能写源 clip 的 localTime 或驱动源图。
5. 用已经存在的一份副本显示采样姿态，保持其余控制变量；自有时钟分别暂停／继续／变速，测试循环和根运动规则。
6. 做数值 A/B，报告参与骨、跳过骨、缩放／位置／旋转误差及参考来源。最终 poseLocal 有混合／IK 时，明确剔除或独立参考，不将单 clip 强行判为错。
7. 观察 O／NPC 隔离；关闭、源图重建或切会话时应停止失效采样。安全销毁没有实现时，只做有限短会话，不通过不停复制积累资源。

### 结果判定

- H01 无活跃身份：只得到名字／索引，未取得运行对象，后续不计通过。
- H02 无持有证明：不进入长期播放，不以字段看起来合理为理由调用候选对象。
- H03 同时刻一致但多相位完全不变：仅证明读取／确定性，不证明播放；核对 clip、时刻、缓存和采样入口。
- H04 位置残差仍存在：对比节点原缩放／采样缩放、nonuniform、CME/helper、根处理及骨映射，不只看总分排名。
- H05 O／NPC 被额外推进、出现无效引用或崩溃：该轮停止，回传原件；S1 保持阻塞。
- 全部 H 成立：通过这一段 clip 的独立采样短测；不是任意 HKX、完整 S2、物理或自动换装已经完成。

发包前缺结构依据或本轮仍无有效对象且没有新证据时停止，不自动追加“再下一跳”。D 录制回放可作为另行明确范围的备选，不静默改验收。

## 备选 D 的最低范围

只在 O 正常更新时被动录制完整时间轨迹，深复制数据和骨表身份，用 P 自有时钟回放。
需验证完整周期／接缝、四元数插值、缩放、根位移与源图重建；未录制的新动作不可播放。
D 不代表任意 HKX 文件加载，也不满足 CBPC／SMP；不能以它的有限成功宣称 FR-03 全部通过。
