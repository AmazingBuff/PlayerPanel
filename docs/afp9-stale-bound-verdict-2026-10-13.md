# AFP9 verdict 7：取景量错了参照物——缓存包围盒停在泊位之前（已修复）

日期：2026-10-13。构建：`CharacterPanel-scopy-AFP9f-…`（用户上机版本；TGA 导出属 AFP9g，画面证据见下）。
现场证据：[AFP9f 会话日志](diagnostics/CharacterPanel-afp9f-park-still-reverted-20261013.log)、
[r01-panel-000 全图](diagnostics/r01-panel-000-full.png)、[中心裁剪](diagnostics/r01-panel-000-center.png)、[放大提亮](diagnostics/r01-panel-000-zoom.png)。

## 1. 首次直接读到画面

AFP9g 的取证导出首次给出摄影棚目标的图像（2560×1440）：

- **画面里有东西，位置也在中心附近**（内容包围盒 NDC x∈[-0.141,-0.080]、y∈[-0.089,0.169]，两帧之间还在移动＝有动画）——**取景算术本身是对的**；
- 但它**只有 78×186 像素**（约占画面高度 13%，远小于预期）、**近乎全黑**（提亮 4 倍才看清：白亮的头盔/头部、深色躯干、垂下的长条、右侧斜出的武器柄）；
- 同时 RenderDoc 抓到的那个 pass 顶点在 spawn 世界坐标（clip.x≈-40300 ≈ 6.27×6425）。

## 2. 根因：定心用的是"缓存几何包围盒"，它停在泊位之前

同一轮日志：

```
R01 frame  center-d=0.0000 world-t-after=(1.7,-484.1,-21.0) anchor=(-0.0,-485.4,-0.0)
R01 census skin-frameID=4187 == render-frame=4187  num-matrices=49
           bone0-world-t=(-1.7,-485.8,16.0)          ← 骨骼确实在锚点
           bound-c=(6425.0,1406.5,252.7)             ← 而几何包围盒仍是 spawn 世界坐标
park-3d    ref-t == ref-now == (6368.8,1450.5,-7804.9)  ← 引用确实泊到了（SetPosition 有效）
           world-t-before=(6425.6,1414.2,189.4)      ← 但引擎每帧把 3D 推回 spawn 位置
```

`figure_skinned_bound()` 读的是几何 `worldBound`——**引擎按自己的节奏刷新的缓存**，在傀儡被泊到 -8000 之后仍停留在泊位前的位置。用它定心，就等于把"错位的中心"摆到锚点：整图被推离锚点约 `8057×0.35≈2820` 单位（纵深），于是**画面更小、离灯更远更暗、还偏出中心**——三条现象一次解释完（`center-d=0.0000` 只证明"delta 把那个旧中心摆到了锚点"，不证明摆对了对象）。

## 3. 修复（AFP9h）

1. **新增 `figure_skeleton_bound()`**：用**本帧自己写下的活数据**定心——遍历 skin palette，取所有骨骼节点的世界坐标求质心与半径；palette 槽位先经"本树节点集合"过滤，绝不直接解引用（沿用 AFP9 崩溃的教训）。
2. 取景改用该包围盒；**缓存包围盒仍一并打印**（`skeleton-bound` vs `cached-bound`），两者差异本身就是要留档的判据。
3. **暂停期也重泊**：`PuppetDriver::tick` 的暂停分支在本帧取景未接管时重写泊位（`PuppetDraw::framing_active()`）——菜单会把世界画在背景里，缺这一步时引擎的每帧重推会让克隆体在面板打开瞬间回到玩家身边（用户 23:45 观察正是如此）。
4. 引用回读确认 `SetPosition` **有效**（`ref-now == ref-t`）；每帧重泊让游玩期克隆体从画面上消失（用户已确认），但**其碰撞/交互体仍在原处**——本轮未解决，记入遗留项。

## 4. 待验证（AFP9h）

1. 面板里人物应**居中、大小正常、有光照**（灯在锚点，图也在锚点）。
2. `R01 frame` 行里 `skeleton-bound` 与 `cached-bound` 应接近（不再差 8000）；若仍相差巨大，说明骨骼世界也没跟着取景走，那就是另一条链。
3. `r01-panel-NNN.tga` 应出现完整人物轮廓；我直接读图判断，不再需要外部帧捕获。
4. 世界侧：游玩期与暂停期都不该看到克隆体；交互提示仍可能出现（遗留）。

## 5. 遗留项

- 傀儡的**交互/碰撞体**仍留在玩家附近（引用已泊位、3D 已移走，但激活射线仍能命中）——需要单独一轮：或让碰撞跟随（`SetMotionType`/`data.location` 同步），或用 `SetActivationBlocked` + 距离门控彻底屏蔽。
