## 二、配对相位（回应 §五.1"源侧是否同相位混合尚未取证"）

gate-5 配对的候选时钟按**突发**推进（completed 2–12 同一 clock_x=0.2083、13–23 同 0.3917——一次墙帧驱动 ~11–12 步），过渡窗 12 对中 11 对落到同一源帧 seq 145（混合完成后）。**但**候选与源的 `1hm_equip` clip localTime 在整个装备段配对中 **min −0.0098 / max +0.0082 s**（n=97）——两侧 clip 相位墙钟锁定、逐帧对齐。因此：过渡窗与衰减尾的超差**不是相位错位**，而是两侧混合路径的形状差（候选直线 ramp vs 源双推进曲线）+ 候选 completed 13–24 的收敛尾。

## 三、对 v116 解读的更正（不改历史裁定行）

v116 的 `advance=frozen-no-step`（装备 3–12 步读数相同）是**突发驱动的读数伪影**：一次墙帧内执行 ~11–12 个驱动步，clip 时钟按墙帧量化推进，突发内读数必然相同。clip 时钟并未冻结——它墙钟锁定，与源侧相位对齐（§二）。v116/v117/v120 的其余读数（捕获≠采样、恒差 2.8、w=k/11 直线）不受影响；H-D1"第二条采样时钟否证"等裁定保留。

## 四、A′ 处置输入（回答 §八.3）

1. **显式建模 `w=k/11` 不可对齐**：源路径是双推进曲线（钟形逐帧差），建模需连混合器语义一起复制——超出回放验证范围，属行为实现改动。
2. **排除窗方案**（推荐）：排除界以**各侧实测混合窗**界定——源侧 = 双 clip 共存帧（本批 ≈0.2 s，帧率波动下按 clip 时钟判定而非记录数）；候选侧 = ramp + 收敛尾（completed 1–24 ≈0.4 s，重判数据实测）。
3. **配对协议**：过渡敏感段需 clip 相位锚定（按贡献 clip 的 localTime 配对），墙钟突发配对在过渡窗退化为多对一。
4. 源侧衰减尾语义已并入 EQ-C5 监视范围之外的部分由正式验证逐会话实测（unequip 域 C″ 是否同为 WeaponAdjustment 衰减仍开放）。
