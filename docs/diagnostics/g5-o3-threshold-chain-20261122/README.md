## 三、限定条件的形式化继承（为什么不是旁路）

[联合验收](../g5-cal-joint-acceptance-20261116/README.md) §六的先例：K5-5/K2-C1/A17"**不阻塞门 4 的 P99 轴冻结，但阻塞 G5 级裁定**"。O-3 要回答的是：新协议（一次新的 G5 级裁定）如何与该先例相容。答案在主张形状：

| 缺项 | 阻塞什么、为什么 | 新协议是否消费 |
| --- | --- | --- |
| **K5-5**（`hkbBlendingBehavior` 等无布局 → 逐骨/通道权重、blend/mask/additive 语义不可观测） | 阻塞**完整姿态/混合等价**与完整 CAL1/门 3——因为无法解释混合分布的内部语义 | **否**。新协议是输出级对照：两侧混合窗的差异由输出可观测的排除窗处置（EQ-W1a 源侧双 clip 共存 / EQ-W1b 候侧 ramp+收敛尾+末段饱和），不需要混合内部观测；§八 明示不证明整体姿态等价 |
| **K2-C1**（护甲 42 槽 + 存档身份缺） | 阻塞完整 CAL1 的"实际控制清单"完备性（装备链泛化表征） | **否**。新协议 §八 限定单装备族/单存档族并要求逐会话重测；冻结场景的装备链已由 K2-C2/C3 登记（武器/手/火把/初始相位/片段族 PASS） |
| **A17 独立控制**（无活动 clip 控制的近似静态共享状态） | 阻塞 116/116 全轨主张 | **否**。继承 G4-COV 方案 A：17 辅助轨描述性账本，不套 tau、不计入主张 |

继承的代价是**裁定语资格**：新协议的 PASS/FAIL 必须写成限定范围裁定（与联合验收的 `CALIBRATED (limited: control-B P99 pose + time + clock axes)` 同形式），显式列出未闭合项——完整 CAL1/门 3、K5-5、K2-C1、A17 独立控制、整体姿态等价。这条写进 §三.4 的裁定措辞要求。

**反模式防线**（对应 O-3 行"本协议不旁路"）：① 阈值数值冻结继承，未放宽、未重推；② K5-5/K2-C1 的处置是 CAL v1 §九许可的范围声明，不是豁免——它们在主张边界里显式列名；③ 不得因本决断把 K5-5/K2-C1 从完整 CAL1 的缺口清单里移除。
