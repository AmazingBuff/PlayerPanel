# C-G5-EQ v1：正式姿态对照的声明差异契约（C′/B，2026-11-21 预注册）

> **状态**：判据契约，预注册定稿；**不授权任何实现、构建、部署或上机**。消费方 = G5 新正式验证协议（联合验收 → 独立校准 → 协议冻结之后）。对应诊断：[C-G5-TRANS §八](../../g5-transition-window.md)（离线拆分）、[C-G5-CHAIN v1](../g5-idle-chain-probe-20261121/README.md)（v121 探针 run1/run2 运行时归因）、[C-G5-E2-B](../../independent-behavior-graph.md#c-g5-e2-b)（源侧后处理三链：足/布料/手臂-挂点）。

## 范围

G5「完整姿态对照」的正式比较（G4P-7 于 2026-11-18 FAIL）已把超差归因为四个成分：A′ 过渡衰减尾（源侧语义未取证，**不在本契约**）、B 挂点槽位平移、C′ 右肩链旋转偏移、时钟阶梯（配对协议层）。本契约只预注册 **B 与 C′ 的声明差异集**（declared divergence set）、其**适用性判据**（每会话复测）与**等值主张的形状**；阈值归属独立校准（CAL），本契约不定任何数值容差。

## 一、问题

正式对照若把"候选 pose ≠ 源 pose"一律判 FAIL，则引擎层差异（武器握持校正、挂点定位）会永远判负，而它们不是候选回放语义的缺陷；反之若无预注册声明集，任何"豁免"都是事后放宽（反模式 13/15 的豁免形态）。契约要回答：**哪些轨、哪些通道、由什么机制、凭什么适用性判据，可以从等值主张中显式声明排除**——且声明集封闭、扩充必须走新契约。

## 五、等值主张形状与阈值归属

1. **等值主张**：除 EQ-DECL-1/2 外，候选↔源逐分量等值（轨集 = 99 主轨 − 5 − 7 = **87 条主轨全通道** + DECL-1 五轨的 translation（t45 除外）+ DECL-2 七轨的 rotation）。
2. **阈值归属**：正式阈值得自 CAL 的 N/Q 推导与独立校准，**本契约不定任何数值容差**；既有 `tau_p/tau_r/tau_s`（门 4 冻结）不改、不放宽；新正式验证若采用新阈值，必须走 CAL 契约，不得引用本契约放权。
3. **测量形状**：EQ-C2/C3 要求"每侧对自身贡献 clip 采样"的三方对照——C-G5-CHAIN 的 IDLE CHAIN 模式已验证可行（v121）；扩展到完整回放序列属新仪器工作，**本契约不授权实现**（见 §八）。
4. **A′（过渡尾）**：等值主张在装备/卸下命令过渡窗的处置（排除窗界或显式建模 `w=k/11`）仍待 [C-G5-TRANS §八.3/§八.6](../../g5-transition-window.md) 源侧语义取证；本契约不预注册任何过渡窗豁免。

## 七、停点与回传

出现下列任一，停止并保留原始记录回评审：声明集外恒差（EQ-C5）、机制证据冲突（EQ-C2 基准量级显著偏离且方向改变）、状态失配（EQ-C1/C1a）、节点在场性翻转（EQ-C4：克隆出现 WeaponAdjustment 或源侧消失）、非有限值/读取失败影响判据覆盖。**不得**：事后扩轨集、把 residual 升格为豁免、以单会话零计数扩大声明、改写历史裁定。回传：每会话 census 差集、三方对照逐轨表、DECL 集逐轨实测值、声明集内/外超差计数、匹配 DLL/PDB/INI 身份与完整日志。
