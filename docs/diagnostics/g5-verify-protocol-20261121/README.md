| 集合 | 定义 | 处置 |

## 三、比较协议（整合项）

### 3.1 配对

- **稳态段**（无过渡、单 clip 贡献）：沿用墙钟配对 + dt 门；候选突发结构下同一墙帧内的多步共享同一 clip 相位，配对允许多对一，**但每对的等值判定必须在"候选 burst 末步 pose"与源帧之间做**（见 O-1）。
- **过渡敏感段**（两侧任一处于混合窗）：墙钟配对禁止（突发退化 11:1）；须以**贡献 clip 的 localTime 相位锚定**。源侧相位 60 Hz 连续；候选侧相位按墙帧量化（突发内不可分辨）——相位锚定在候选侧的分辨上限 = 突发粒度（O-1）。

### 3.2 排除窗（从 FAIL 计数排除，数据照记）

| 窗 | 界定 | 依据 |
| --- | --- | --- |
| **EQ-W1a 源侧混合窗** | 每命令**双 clip 共存帧集合**（按贡献 clip 出现/消失判定，帧率波动下按 clip 时钟而非记录数） | [源侧过渡语义](../g5-source-blend-20261121/README.md)：四窗实测 ≈0.2 s、钟形路径 |
| **EQ-W1b 候选侧混合窗** | 每命令 injected 事件后 **completed 1–24**（直线 ramp 1–12 + 收敛尾 13–24；精确尾界由 O-1 复核后冻结） | 同上 §二 + 重判数据 |
| **EQ-W2 声明差异集** | EQ-DECL-1/2 的轨×通道 | C-G5-EQ v1 §三 |

排除 = 不进 FAIL 计数；**窗口内逐对误差、逐轨值全部保留在明细里**（rejudge 模式），排除不等于删除。

### 3.3 会话适用性判据（每会话先复测，任一失败 ⇒ 本会话对声明集不适用）

EQ-C1 状态同域 / EQ-C1a MLh 家族集一致 / EQ-C2 机制在场 / EQ-C3 候选忠实 / EQ-C4 节点在场性 / EQ-C5 无新恒差——定义见 [C-G5-EQ v1 §四](../g5-eq-contract-20261121/README.md)；测量点复用 v121 IDLE CHAIN 探针模式（census + 三方对照）。

### 3.4 判定输出（每会话）

机械计数 + 分组明细，不做文字裁定：等值集超差计数与逐轨排名、DECL 集逐轨实测值与基准比对、residual 集逐轨计数、排除窗内统计（单独列示）、EQ-C1..C5 各自结果、配对账本（对数、多对一结构、相位差分布）。裁定措辞由运行记录写（与 gate-5 惯例同）。
