## 五、对 G5 的直接影响

1. **装备窗口的前 11 帧是过渡混合**，不是纯 clip 播放。候选在这个窗口的姿态由 `A→B` 的线性混合决定，而 `B` 是过渡启动时存下的 `to` 快照（`localTime` 0.2083），所以 `localTime` 冻结也不影响姿态变化。
2. 因此门 5 的「同时间配对」在这段里注定不成立：一侧在播混合、另一侧（源）未必同相位混合。v103 正式批次里装备段的 `E_p`/`E_r` 超差（`Quiver`/`WeaponAxe` 等 5 条静态附件占 1,240 次平移超差之外，body 1,226 次）与这里的过渡混合同源的概率很高。
