# C-G5-STATE v1：候选过渡状态空间审计（2026-11-17，POST-HOC COMPLETE）

**状态：POST-HOC 描述性审计，已完成；不改变门 4/门 5 判据，不改变 G4P-7 FAIL，不产生 `tau_*`。** 本审计回答“同一 clip local_time 下为什么候选仍有多条不同姿态”，并区分单标量混合、初始状态和真实轨迹差异。

## 一、背景

[C-G5-CLOCK v2](../g5-clock-step-20261117/README.md) 已证明：

- 候选 equip/unequip/idle 只有 17/21/3 个唯一 clip `local_time`；
- 所有多记录 local_time 组的 116 轨完整姿态都不同（8/8、10/10、2/2 全唯一）；
- 当前 nearest-clock 配对因此把大量候选姿态配到同一源记录。

本审计检查这些同组姿态的**状态维度**：它们是一条单标量混合曲线，还是多条独立轨迹？以及它们是否落在源侧姿态轨迹上。

## 二、方法

- 输入：门 5 正式 CPK5/CPK5S、K1 census 骨名；body = 88 条非 attachment、非 A17 轨。
- 对每个候选 local_time 组（记录数 >1）：将每条记录的 116×10 track 展平为 1160 维向量，去均值后做 PCA；报告 PC1/PC2/PC3 方差占比，以及 PC1 投影是否随记录顺序单调。
- 对组内每条候选记录，在**同 domain 的全部源记录**中按 body 88 骨的逐骨平移最大 `E_p` 找最近源姿态；报告组内最近源残差的 median/max。该量只用于判断“是否在源轨迹上”，不是配对判据。
- 这是一次事后离线分析；PCA/最近源残差不进入 G4P-7 正式裁定。

## 三、结果

### 3.1 单标量混合

所有多记录组的 PC1 方差占比为 **0.9983–0.999998**，PC1 投影随记录顺序全部单调：

| family | 多记录组 | PC1 最小 | PC2 最大 | PC3 最大 | 单调组 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1hm_equip | 8 | 0.998297 | 0.001687 | 1.5e-5 | 8/8 |
| 1hm_unequip | 10 | 0.998993 | 0.000969 | 3.8e-5 | 10/10 |
| 1hm_idle | 2 | 0.999957 | 4.3e-5 | 0 | 2/2 |

结论：同一 local_time 下的候选姿态不是任意噪声，而是沿**一个标量轴**的单调混合曲线；该轴很可能就是过渡 blend/权重状态。K5-5 的“权重不可观测”在本数据上表现为一个主要标量，而不是多个独立自由度。

## 四、解释

1. **equip 第一组是离轨的初始过渡**：`0.208333` 组的候选姿态最近源残差 median `0.324`、max `0.497`；后续 equip 组降到 ≤0.0856，末段 ≤0.0076。这不是时钟分辨率能解释的，候选从不同的初始姿态出发，沿一条源轨迹上没有的混合弦进入 equip。
2. **unequip/idle 基本在源轨迹上**：unequip 后段与 idle 的最近源残差 ≤1.5e-5/3.3e-5；当前大误差主要来自“同一姿态被配到单一源记录”的时钟阶梯，而不是轨迹本身。
3. **单标量轴是 K5-5 的核心缺项**：组内 PC1 占 99.8%+ 且单调；当前 CPK5 只记录 clip local_time，没有记录这个 blend/权重标量，故同一 local_time 的多个姿态无法在协议内区分。
4. **初始状态与静态附件 H2 是两个不同问题**：H2 解释 5 个静态附件骨的 1,240 次偏移；本审计的 equip 第一组离轨解释 body 的主要过渡残差。二者都不能靠事后删轨或放宽 tau 解决。

## 五、裁定与下一入口

**G4P-7 仍 FAIL，G5 未通过。** 本审计的结论把下一工作包收敛为两个可预注册的设计问题：

- **A. 初始姿态/状态 bootstrap**：候选在注入前与源初态不同；需预注册“从源 baseline 初始化候选 pose/1H idle 栈”或等价方案，并在新采集上验证第一组是否回到源轨迹。
- **B. 单标量 blend/权重状态采集**：当前 CPK5 没有该标量；需预注册一个只读状态观测（层/权重/fraction）并把配对从单 clip 时钟改为“clip 时钟 + 状态标量”。

两项都必须新采集、新预注册；本批数据只能作为归因证据。静态附件 H2 轴另行处理。
