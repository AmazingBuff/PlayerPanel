## 四、裁定

1. **A17 没有独立动画控制**：活动 clip 不覆盖它们；不能从现有 K5/MT_Idle 真值推出独立容差。
2. **A17 近似静态共享状态**：跨记录 span ≤3.8e-6，跨侧差 ≤1.97e-6；不是独立行为差异来源。
3. **不能据此声称 116/116 等价**：这是观测到的共享状态一致，不是独立控制；A17 的参考/驱动来源仍未闭合。
4. **COV 方案 A 继续有效**：P99 主分母 + A17 描述性账本，不套 CAL1-B tau，不判 PASS/FAIL，不声称 116/116。
