## 五、C/B 合流判断（回答 §八.5，2026-11-21 按 §六 溯源结果修订）

- **B 与 C′/C″ 是两个不同机制，不宜并成一个契约**：B（t60–66 挂点）是**旋转逐位相等下的恒定平移差**＝纯槽位状态差；C′（R 肩链）是**恒定旋转差**＝源侧位姿修改层差。两者都"非过渡、非时序"，但对象与机制不同，预注册时应分立两个相等性契约（B：槽位挂点平移相等性；C′：R 肩链位姿/修改层语义）。
- **C 的"底噪"不存在独立机制**：§八.2 溯源（§六）证明 settle 下没有一条轨是浮点求值噪声形状——77 条差异轨分属 C′ 修改层差（5 轨）、手指微差（~9 轨，可能同属握持层）、时钟阶梯差（动画骨 0.1–1.4° varying，随候选 0.05s 步进时钟）。原 §五"底噪不并入"的表述按此修订。
- **A 的排除窗不足**：equip 尖峰 burst 证明过渡影响延伸到 comp ≈24（第一命令尾）；A 处置（排除或建模 `w=k/11`）的窗口界定需按 §八.3 的源侧取证重新推导。

**机制裁定**：底噪的三种真实成分——
1. **R 肩链修改层差（C′，最大超差来源）**：同剪辑、同参考、同映射下，源侧（live 全管线）在 1hm 持武器/卸下状态对 t30/31/58/59/45 输出与纯剪辑采样不同的恒定偏移；候选直驱＝剪辑原值。与 [G4 交联机制](../../independent-behavior-graph.md)的"OAR 装载期写入共享模板树"及引擎握持/瞄准类修正一致候选，**归因（OAR 注入层 vs 引擎层）须运行时探针（§八.5）**；两侧孰为"剪辑原值"亦由该探针定（候选直驱语义上应为原值，但本分析未读剪辑原始轨数据，不作断言）。
2. **手指微差（~9 轨 0.8–3.7° varying）**：左手手指张开度不同，疑似同属握持层。
3. **时钟阶梯差（动画骨 0.1–1.4° varying）**：候选 local_time 0.05s 步进 vs 源连续时钟，≤25ms 采样错位；属 A/E1 已知机制（候选时钟阶梯），处置在配对协议而非新机制。
