## 一、结论（TL;DR）

1. **候选 pose 在 burst 内逐步推进、观测时钟恒定**：249 条候选记录按观测 clip localTime 分成 **41 个 burst**（equip 17 / idle 3 / unequip 21，尺寸 1–15）。burst 内报告的 clip localTime 不更新，而内部采样相位每 completed 步 +1/60——稳态 idle 每步 ~0.5°、装备/卸下快速段每步最高 ~10°（t31 逐 burst 实测）。
2. **burst 末步 = 与配对源帧相位对齐的成员（v0 选点实证正确）**：全部正常播放 burst 的逐成员 vs 源误差单调线性递减、argmin=末步（15/15）；idle 非 C′ 漂移从 m0 的 7.5° 单调衰减到末步的 1.25°；burst 边界相位连续恰差 1 步。其余 argmin 例外恰为 C′ 恒差掩盖的 idle burst（30.32° vs 30.33°）与 clip 时长终点冻结边界。
3. **正式批次的超差主体是配对粒度伪影**：mid-burst 188 对（占 248 对的 76%）承载 **tau_p 76% / tau_r 79% / tau_s 72%**。这些对把相位滞后最多 (n−1)/60 ≈ 0.23 s 的候选 pose 与 burst 末端源帧比较——重判"尖峰"成分（每对 1–29 轨、5°–70°）的主体即此伪影，集中在快速运动轨（臂/武器链），解释了其"少数骨相位不同"的形态。**这是对超差机理的前进修正，不改变重判数值。**
4. **选项 (a) 下剩余 FAIL 与既有契约结构一致**：端点集（41 对）超差 606/2,198/72；叠加 EQ-W1b（33 对）为 **407/1,661/0**——DECL2 占 tau_p 57%（231/407）、DECL1 在 idle 端点在场（t31 ≈30°）、残差 tau_r 全部 ≤1.2°（Spine1/2、Neck/Head 等动画骨阶梯形）。冻结容差下的这些计数只是灵敏度测量，不是新裁定。
5. **推荐 (a)、拒绝 (b)/(c)**：(b) 把 76% 的对声明为"回放自身粒度"后等值集收缩到同一批端点，纯属更重的声明 + 多对一记账噪声，被 (a) 严格支配；(c) 拆除的正是显示链墙钟锁定（突发=帧抖动下的追赶机制），是行为实现改动且验证的是另一个东西。

## 五、三选项评估

| 选项 | 评估 |
| --- | --- |
| **(a) 比较单元 = burst 末步** | **推荐**。等值集 = 41 端点（+W1b 后 33）；末步为实证相位真值成员；mid-burst 伪影整体移出等值集；剩余超差与 C-G5-EQ v1 的 DECL/残差结构一致，可由既有契约 + CAL 阈值链（O-3）处置。 |
| (b) 每步比较 + 声明突发内 ramp 步 | 拒绝。被证伪的不是 ramp 步而是**全部** mid-burst 成员（含正常播放 burst）；声明集须覆盖 188/248 对（76%），等值集收缩到与 (a) 相同的 41 端点——(b) = (a) + 更重的声明 + 多对一记账噪声，被严格支配。 |
| (c) 驱动语义改造（1 步/墙帧） | 拒绝。突发是显示链**墙钟锁定**的实现机制（帧抖动下的追赶），1 步/墙帧会在长帧上使预览相位脱离世界动画时钟——产品语义变更；纯测试驱动则验证的不是产品回放路径。另需行为契约并使既有回放证据链（G3-B/F、v96a–v121）失去可比性。 |

## 六、v1 需吸收的修正（若采纳 (a)）

1. **§3.1 比较单元措辞**：定义为"burst 内最后一个 completed 的记录"，并写明实证依据（argmin=末步 15/15、idle 非 C′ 漂移单调衰减至末步、边界相位连续恰 1 步）；相位残差由 `dt_clock ≤ ε_t` 界定，不引入 rigid 锁存模型。§3.1 过渡敏感段的相位锚定机械大部分被 EQ-W1a/W1b 排除窗覆盖，v1 可相应简化。
2. **残差集"时钟阶梯"条目幅界修正（对 §八.2③ 的前进更正）**：其"≤25 ms"是时钟**值**一致；**姿态相位**一致只在 burst 末步成立，mid-burst 成员相位滞后可达 (n−1)/60 ≈ 0.23 s（本批 idle 非 C′ 漂移 7.5°、装备段可达 ~100°）。在 (a) 下阶梯残差 = 端点相位量化，本批端点实测 max ≤1.2°。settle 分析的 0.1–1.4° 特征在端点集上成立；mid-burst 读数不再进入等值集。
3. **clip 时长终点冻结边界的显式处置**：优先钟在时长终点冻结的 burst（equip c87–98、unequip 尾部）末步不被优先钟锚定（c98 端点 66.8°）。v1 须二选一并预注册：并入 EQ-W1a 等价窗（源侧 equip→idle / unequip→mt 混合窗），或改用次优先钟/贡献 clip 锚定。
4. **EQ-W1b 上界维持 24**；候选侧混合窗的精确尾界按重判数据（comp 12→24 的端点超差衰减 ~30/~130）维持现值。
5. **残差集数值重推导**：C″（unequip 右臂差）衰减剖面、手指微差等曾在 mid-burst 相位伪影混入下测量；新协议的 rejudge/判定步骤改用端点集重推导（本稿 §四的 33 对集即基底）。
