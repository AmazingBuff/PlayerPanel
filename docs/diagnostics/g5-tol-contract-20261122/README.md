## 二、零假设测量（推导基础）

两份已归档源侧批次（gate-5 v103 849 条 + VER v122 1,145 条；同 save/modlist/场景族）跨会话自配对——**源管线自身的会话间波动即良性差异的天然上界**。脚本 [measure_null.py](measure_null.py)（纯 stdlib、只读、复现：`python -B …/measure_null.py`）：

- 471 对（dt ≤ 1/120 s；equip 50 / idle 197 / unequip 71 / mt 153）；排除 IDUN 与双主族共存（过渡窗）
- **总体分布重尾**：p50 = 0（多数分量逐位相同）→ p95 0.32° → p99 **2.83°** → max **24.21°**
- 重尾集中在手指/握持态轨：t70/79/76/73 p99 **20.8–23.1°**（手指姿态为会话态，源自身跨会话即差这么多）、t43（Weapon 平移）p99 2.31

**结论**：单一全局容差不可行（手指轨与身体轨的良性带差一个数量级）；必须逐轨。

## 六、边界

- 本契约不触碰门 4 冻结 `tau_*`、不证明整体姿态等价、不关闭 G6/K5-5/K2-C1/A17/装载 teardown。
- 逐轨界绑定两次源会话的零假设（同机/同存档族/单装备族）；换骨架/装备族/大版本须重测零假设并重生成表。
- 手指/武器轨的宽界反映**会话态**（握持、附件状态非姿态语义）；若未来要验证手指姿态语义本身，须另立"同会话手指对照"契约（源与候选同帧同态）。
- 28 笔接受超差如未来需要收敛：MLh 缺口族 = G6 克隆收敛工作项；C″ = 卸下域右臂差（量级随 settle 衰减，已知）。
