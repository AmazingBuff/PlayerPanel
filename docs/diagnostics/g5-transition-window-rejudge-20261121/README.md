## 六、旋转的两种形状：底噪 + 尖峰（2026-11-21 追加）

### 6.1 逐轨：重尾，没有"常值偏移"

对窗外 236 对逐轨统计 `E_r`：**99 条主轨里 87 条有数据，全部 CoV（std/mean）≥ 1**（`{cov<0.1: 0, 0.1–0.3: 0, 0.3–1: 0, ≥1: 87}`）。即每条轨都是"一个底噪 + 偶发大值"，而不是固定角度偏移；equip 段与 unequip 段的逐轨均值也明显不同（`|equip−unequip|/max` 中位 0.603、p90 0.887），进一步排除"每轨常值校准"。

`E_r` 均值最大的轨：`t31` 2.50e-2（≈26°）、`t58` 1.55e-2、`t39` 1.50e-2、`t43` 7.89e-3、`t56` 6.75e-3、`t67` 5.99e-3、`t38` 5.46e-3、`t28` 5.46e-3；对应 std 为 1.4e-2–4.3e-2，全部大于均值。

## 七、裁定与影响

1. `G4P-7` 维持 **FAIL**：丢弃过渡窗后 `tau_p` 仍有 3,012、`tau_r` 仍有 15,805。
2. 失败现在拆成**三个成分**，各自需要独立预注册或独立调查：
   - **A 过渡混合窗**（装备 `completed 1–12`，≈0.2 s，`w = k/11` 已实测）：**全部 352 次 scale 超差**、21% 平移、6% 旋转。处置：排除出配对，或在配对里显式建模权重。
   - **B 静态平移偏移**：窗外平移超差塌缩到 **20 条轨**（`track45`、`track60–66` 等），每条几乎每对都超、幅度恒定——即 v105 归因里的静态附件轴，任何时间对齐或放宽容差都无效。
   - **C 旋转差异（两种形状叠加）**：底噪（几乎所有轨 1e-5 ≈0.5°，超 0.04° 阈值约 12 倍）+ 尖峰（155/236 对里各有 1–6 根轨到 5°–70°，如 `t39/t43/t46/t30/t4/t6`、`t58/t82/t31/t59`）。逐轨 CoV 全部 ≥1、两段均值差中位 0.603，排除「每轨常值偏移」；既不随过渡窗消失，也不属于静态平移那 20 条轨。
3. 旋转轴当前的阈值实际上是「位精确」级别：它与中位误差差两个数量级，因此该轴更像"是否逐位相同"的判据，而不是"姿态容差"判据。若要把它当容差用，需要另立契约重新推导，不能在本轮事后放宽。
4. 下一步只需两件事（都离线）：把 `track` 映射到骨骼名（K1 普查/日志里已有 `animationSkeleton->bones[i].name` 的采集路径），看尖峰落在哪些骨上；以及对底噪做一次「两侧同帧、同一骨链」的定点比较，确认它是否来自参考姿态或累积顺序。
